# Lynx Outdoor Designs

Static site (HTML/CSS/JS, no build step). All files live at the repository root,
including the images (logo.jpg, side.jpg, wall.jpg, grass.jpg, favicon.png).

## Deploy (GitHub Pages)
Settings -> Pages -> Source: Deploy from a branch -> main -> / (root) -> Save.

## Quote form
Posts to Formspree; leads email to lynxoutdoordesigns@gmail.com. The first
submission triggers a one-time confirmation email that must be clicked.
